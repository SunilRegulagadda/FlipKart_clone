

# Flipkart Clone

## 🚀 Getting Started

### 1. Clone the Repository
Run this command in your terminal to clone the project:
```bash
git clone https://github.com/SunilRegulagadda/FlipKart_clone.git


This will download the project into a folder called FlipKart_clone.

2. Install Dependencies

Go to the project folder and install all required libraries:

cd FlipKart_clone
npm install

3. Start the Project

Run the development server with:

npm run dev


Now you can start coding!
Add your own components inside the components folder.

📤 Pushing Code to GitHub

When you make changes and want to upload them to GitHub:

git add .
git commit -m "your message here"
git push origin main


(You only need git init, git remote add, etc. for the first time setup. After that, just use the above 3 commands.)

📥 Pulling Latest Code from GitHub

If someone else has updated the project and you want the latest version:

git reset --hard       # removes your local changes
git pull origin main   # downloads the latest code
